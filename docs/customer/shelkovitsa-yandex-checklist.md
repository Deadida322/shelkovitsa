# Шелковица: что нужно сделать для Яндекс Доставки и Маркета

26 октября 2026

## 1. Что получить

Без этих регистраций и доступов подключение не начать. Токены и ключи передавайте разработчику через менеджер паролей, не открытым текстом в мессенджере.

| Что | Где и как | Что передать разработчику |
| --- | --- | --- |
| Регистрация в «Честном знаке» | [честныйзнак.рф](https://честныйзнак.рф), нужна электронная подпись. Бельё, купальники и носки продаются только с маркировкой — и на сайте, и на Маркете | подтверждение регистрации |
| Коды маркировки на товары | у поставщика или заказать в «Честном знаке» | коды по мере получения |
| Штрихкоды GTIN для 2 343 вариантов (сейчас там внутренние коды, начинаются на 2) | у поставщика или через [ГС1 РУС](https://gs1ru.org) | таблица: код варианта → GTIN |
| Кабинет Яндекс Доставки | [dostavka.yandex.ru](https://dostavka.yandex.ru/auth/list) → войти через Яндекс ID компании → ввести ИНН → принять оферту → пополнить баланс от 1 ₽. Нужен расчётный счёт ИП или ООО | — |
| Токен Доставки | кабинет Доставки → «Интеграция» → «Получить токен». После смены пароля кабинета токен нужно получить заново | токен |
| ID склада отгрузки | кабинет Доставки → «Адреса» → добавить склад → запланировать отгрузку в «Календаре отгрузок» → попросить «ID станции» в чате поддержки | ID станции |
| Кабинет продавца Яндекс Маркета | [partner.market.yandex.ru](https://partner.market.yandex.ru), нужен ИП или ООО | API-ключ и номер кабинета |
| ИНН и ставка НДС | бухгалтерия | ИНН, ставка НДС |

## 2. Что заполнить

Добавьте в выгрузку товаров новые колонки в конец таблицы. Существующие колонки не меняйте.

| Колонка | Что писать | Пример |
| --- | --- | --- |
| Вес брутто, г | вес товара вместе с упаковкой | 120 |
| Длина, см / Ширина, см / Высота, см | размеры упакованного товара, округлить вверх | 25 / 18 / 3 |
| Остаток | точное число вместо «>5» | 12 |
| Пол | Женский, Мужской, Детский или Унисекс | Женский |
| Размерная сетка | RU или INT, для бюстгальтеров EU | RU |

Вес и размеры не нужно мерить на каждом артикуле. Достаточно взвесить и измерить 2–3 пакета на каждый тип товара (трусы, бюстгальтеры, купальники…) и записать таблицей «тип товара → вес и размеры».

Штрихкоды GTIN из раздела 1 вписывайте в существующую колонку «Штрих-код» вместо внутренних кодов. Коды маркировки в выгрузку не нужны — они учитываются отдельно, по каждой единице товара.

## 3. Что исправить

### В выгрузке товаров

| Что исправить | Строк | Как |
| --- | --- | --- |
| В «Категории» или «Типе» стоит «Коллекция …», «Распродажа», «Образцы», «Некондиция», «Уценка» | 12 227 | указать настоящий тип: Бюстгальтер, Трусы, Купальник… Распродажу отмечать только в колонке «Распродажа» |
| Описание короче 400 символов | 32 258 (90%) | дописать до 400–600 символов: материал, посадка, для чего товар |
| Нет описания | 23 | написать |
| Нет состава | 1 053 | заполнить колонку «Состав» |
| Нет цвета (Lolita, Julimex, Amelie, Mioocchi, Mia-Mia, Albina L, Philippe Matignon, Gentlemen) | 62 | указать цвет; для товаров без цвета писать «Без цвета» |
| Нет размера | 10 | указать размер |
| Штрихкод с ошибкой | 11 | запросить верные у поставщика |

### В файлах соответствий цветов и размеров

В файлах `colors.xlsx` и `sizes.xlsx` первая колонка — как у поставщика, вторая — как на сайте. Исправленные файлы пришлите разработчику.

| Файл | Что исправить | Как |
| --- | --- | --- |
| colors.xlsx | «Прозрачный» записан дважды: в строке 512 → «Прозрачный», в строке 574 → «Разноцветный» | оставить одну строку |
| colors.xlsx | нет цветов Belweiss: у этого бренда цвет записан номером (1, 8, 9, 10, 11, 25, 43, 51 и др., 28 номеров, 504 строки) | запросить палитру «номер → цвет» у поставщика и добавить |
| colors.xlsx | нет цветов: Blu/Turchese, 131_Turquoise, TI_мелкий_узор/бирюзовый, BI_Какаду/Голубой, OI_Черепаха/Коралловый | добавить |
| colors.xlsx | разные цвета поставщика стали одним цветом на сайте: например, Dune и Nilo → «Бежевый». На сайте такой товар показывается одним вариантом, и остаток одного цвета теряется | дать таким цветам разные названия на сайте («Песочный», «Нюдовый») |
| sizes.xlsx | «46D/L» записан дважды: строка 244 → «48D», строка 245 → «48L» | оставить одну строку |
| sizes.xlsx | нет размеров: UN (универсальный, 117 строк), 45/47, детские 3/4, 5/6, 9/10, 11/12 | добавить, например UN → «Единый» |

## 4. Какие решения принять

| Вопрос | Варианты | Решение |
| --- | --- | --- |
| Как платит покупатель | онлайн на сайте (нужен договор с платёжным сервисом, например ЮKassa, и онлайн-касса) / при получении (деньги придут от Доставки за вычетом её услуг) / оба | |
| Куда доставлять | пункты выдачи / курьер до двери / оба | |
| Кто платит за доставку | покупатель / бесплатно от суммы заказа / фиксированная цена | |
| Примерка в пункте выдачи | разрешить / нет (есть не во всех пунктах) | |
| Частичный выкуп | разрешить забрать часть заказа / только целиком | |
| Как отдавать посылки Доставке | курьер забирает со склада / сами отвезёте в сортировочный центр или пункт выдачи | |
| Как работать с Маркетом | DBS — храните и доставляете сами через Яндекс Доставку / FBS — храните сами, заказы забирает Маркет | |

## 5. Как сохранять выгрузку

Excel может испортить данные: штрихкод 8422091144289 превращается в 8,42209E+12, а размер 3/4 — в дату «3 апреля». Чтобы этого не было:

1. Колонкам «Код», «Размер» и «Штрих-код» задайте формат «Текстовый» до того, как вставлять данные.
2. Сохраняйте в формате .xlsx. Старый .xls и CSV не подходят.
3. Первая строка — заголовки. Порядок и названия старых колонок не меняйте, новые добавляйте в конец.
4. Одна строка — один вариант товара (артикул + цвет + размер).
5. Все данные — на первом листе; файл не больше 20 МБ.
